Admin প্রবেশ

Admin UID Firebase Authentication-এ যাচাই করা হবে। শুধু ইমেল জানলেই Admin হওয়া যাবে না।

প্রথমে Firebase সেটআপ করে আপনার UID ADMIN_UID ঘরে বসাতে হবে এবং Firestore Security Rules প্রকাশ করতে হবে।
